# Shiodoki のデータとプライバシー

Shiodoki は個人（Kaoru Kajihara、以下「管理者」）が作り、知人に使ってもらっているアプリです。
保存するデータと、それを誰が見られるかを説明します。

[English](../en/privacy.md)

## 2 つの使い方

| 使い方                     | データの保存先                       | 管理者に見えるもの                                   |
| -------------------------- | ------------------------------------ | ---------------------------------------------------- |
| この PC だけで使う（推奨） | あなたの PC だけ                     | なし                                                 |
| Google でログインして使う  | あなたの PC と、クラウド（Firebase） | タスク名とメモ以外（下の表で「暗号化しない」の項目） |

1 台の PC で使うなら、「この PC だけで使う」をおすすめします。

利用状況の解析や広告のためのツールは、どちらの使い方でも使っていません。データを売ったり、第三者に渡したりしません。

Windows 版は起動したときに、新しいバージョンがあるかを GitHub に問い合わせます。このとき、タスクなどのデータは送りません。

## この PC だけで使う場合

データはあなたの PC の `store.json`（Windows：`%APPDATA%\shiodoki\store.json`、Ubuntu：`~/.config/shiodoki/store.json`）にだけ保存され、インターネットには送りません。
管理者を含め、PC の外の人には見えません。

このファイルは暗号化していないので、PC を使える人なら中身を読めます。

## Google でログインして使う場合

次のデータを Google の Firebase（Cloud Firestore と Firebase Authentication）に保存します。

| データ         | 暗号化する                                   | 暗号化しない                                                                              |
| -------------- | -------------------------------------------- | ----------------------------------------------------------------------------------------- |
| アカウント     | なし                                         | Google アカウントのメールアドレス、名前、プロフィール画像の URL、Firebase が割り当てる ID |
| タスク         | タスク名、メモ                               | 分類、並び順、完了したか、削除したか、作業時間の累計、作成・更新・完了の日時              |
| 作業セッション | タスク名                                     | どのタスクか（ID）、いつからいつまで、何分したか、PC かスマホか                           |
| PC の状況      | 作業中のタスク名                             | タスクを選んでいるか、作業中か、作業ストップ中かなどと、その時刻。起動中は 5 分ごとに更新 |
| 暗号を解く鍵   | 鍵そのもの（パスフレーズと回復キーで暗号化） | 鍵を作るときの設定（計算の回数など）                                                      |

PC にもオフラインで使うためのコピーと設定（表示言語など）を保存します。

### 暗号化のしくみ

- タスク名とメモは、あなたの PC で暗号化してから送ります（エンドツーエンド暗号化）。クラウドには暗号化した文字列しかありません。
- 暗号を解く鍵はあなたのパスフレーズか回復キーがないと取り出せません。パスフレーズと回復キーは、クラウドにも管理者にも送りません。
- 解除した鍵は、OS が用意している安全な保存場所（Windows の DPAPI など）に PC ごとに保存し、ログアウトすると消します。
- 暗号化した文字列の長さから、タスク名やメモの **おおよその文字数** はわかります。

### 誰が見られるか

- あなた：アプリから、自分のデータだけを見たり変更したりできます。ほかの利用者のデータは見られません（Firestore のセキュリティルールで制限しています）。
- 管理者：Firebase プロジェクトのオーナーなので、Firebase のコンソールからすべての利用者のデータを見られます。ただし、タスク名とメモは暗号化されているので読めません。見えるのは、上の表の「暗号化しない」の項目（いつ、何分作業したか、タスクの数や分類など）です。管理者は、あなたに頼まれて不具合を調べるとき以外は、これも見ません。
- Google：データは Google のサーバーに保存されます（[Firebase のプライバシーとセキュリティ](https://firebase.google.com/support/privacy)）。Google にも暗号化した項目は読めません。

パスフレーズと回復キーの両方をなくすと、暗号化した項目は誰にも読めなくなります。管理者も元に戻せません。

## データの削除

- タスクの削除はアプリの画面からできます。ログインして使っている場合、データベースからは消えず、削除したという印が付くだけです（ほかの端末と同期するため）。
- ログインせずに使っている場合は、`store.json` を消すと、すべてのデータが消えます。
- アプリでログアウトすると、この PC に保存されたデータと暗号を解く鍵は消えます。クラウドのデータは残ります。
- **クラウドのデータをすべて消したい**とき（使うのをやめるときなど）は、管理者に連絡してください。アカウントとすべてのデータを削除します。
