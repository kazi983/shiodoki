# Shiodoki デスクトップ版の使い方

Shiodoki（潮時）は 30 分ごとに「今から何をやる？」と聞いて、取り組むタスクを 1 つ選ばせるアプリです。
タスクごとの作業時間を記録し、次の予定の時刻が近づくと警告して、作業を止めます。

[English](../en/desktop.md)

## 必要なもの

- Windows 10 / 11、または Ubuntu
- Google アカウント（ほかの PC と同期するときだけ。ログインせずにも使えます）
  - 今は試験運用中のため、ログインできるのは管理者が登録したアカウントだけです。使う Gmail アドレスを管理者に伝えてください。

## インストール

### Windows

1. [GitHub の Releases](https://github.com/kazi983/shiodoki/releases) から `Shiodoki-Setup-<バージョン>.exe` をダウンロードして開きます。
2. 「Windows によって PC が保護されました」と表示されたら、「詳細情報」→「実行」を押します。
   - アプリにコード署名（有料の証明書）をしていないため表示されます。
3. 確認の画面なしでインストールされ、Shiodoki が起動します。スタートメニューとデスクトップにショートカットができます。
4. タスクバー右下の「^」を押すと、Shiodoki のアイコンがあります。ドラッグしてタスクバーに出しておくと、操作しやすくなります。

#### ログイン時に自動で起動する（任意）

Windows 版には自動で起動する設定がまだありません。次の手順で、Windows のスタートアップに登録できます。

1. スタートメニューで Shiodoki を右クリック →「詳細」→「ファイルの場所を開く」。
2. `Windows キー + R` を押し、`shell:startup` と入力して Enter。スタートアップのフォルダが開きます。
3. 1 で開いたフォルダの「Shiodoki」のショートカットを、2 のフォルダにコピーします。

### Ubuntu

[GitHub の Releases](https://github.com/kazi983/shiodoki/releases) から `.deb` ファイルをダウンロードして、インストールします。

```bash
sudo apt install ./shiodoki_<バージョン>_amd64.deb
```

- トレイアイコンを表示するには、GNOME 拡張機能「AppIndicator and KStatusNotifierItem Support」が必要です（なくてもアプリは動きます）。
- ログイン時と画面のロック解除時に自動で起動するには、[desktop/linux/README.md](../../../desktop/linux/README.md) の手順で設定します。

## はじめての起動

最初の画面で、データをどこに保存するかを選びます。選んだ方法は記憶され、次からはこの画面は出ません。

| ボタン                    | データの保存先     | 向いている人                                                       |
| ------------------------- | ------------------ | ------------------------------------------------------------------ |
| この PC だけで使う        | この PC だけ       | 1 台の PC で使う人。**迷ったらこちら**。管理者もデータを見られない |
| Google でログインして同期 | クラウド（暗号化） | 複数の PC で同じタスクを使いたい人                                 |

どちらを選んでも、あとから変えられます（[保存先を変える](#保存先を変える)）。
詳しくは [データとプライバシー](privacy.md) を見てください。

### この PC だけで使う

「この PC だけで使う」を押すと、すぐに使い始められます。インターネットにつながっていなくても動きます。
データはこの PC の `store.json` というファイルにだけ保存されます（[データの保存場所](#データの保存場所)）。

### Google でログインして同期する

1. 「Google でログインして同期」を押すと、ブラウザが開きます。
2. 「Google はこのアプリを確認していません」と表示されたら、「続行」を押します。
   - 個人が作ったアプリで、Google の審査を受けていないために表示されます。
   - 「アクセスをブロック」と表示されてログインできない場合は、そのアカウントがまだ登録されていません。管理者に連絡してください。
3. ブラウザに「ログインしました」と表示されたら、そのタブを閉じてアプリに戻ります。
4. 暗号化の設定をします（次の節）。

2 回目からはログインしたままになり、インターネットにつながっていなくても使えます。
オフラインの間の変更はこの PC に保存され、つながったときに自動で送信されます。

### 暗号化の設定（ログインしたときだけ）

クラウドに送るタスク名とメモは、この PC で暗号化してから送ります。
暗号を解く鍵はあなたの **パスフレーズ** か **回復キー** がないと取り出せません。管理者にも読めません。

**はじめてログインしたとき**

1. パスフレーズを決めます（10 文字以上）。覚えやすい長めの文がおすすめです。
2. 回復キーが 1 度だけ表示されます。「コピー」か「ファイルに保存」で控えて、パスワードマネージャーなど安全な場所に保管します。
3. 「回復キーを保存しました」にチェックを入れて進みます。

**ほかの PC でログインしたとき**

ログインのあとで、パスフレーズか回復キーを入力します。一度入力すれば、その PC ではログアウトするまで聞かれません。

> **パスフレーズと回復キーの両方をなくすと、クラウドのデータは誰にも読めなくなります**。管理者も元に戻せません。

パスフレーズの変更と回復キーの再発行は、トレイメニューの「暗号化…」からできます。

## 使い方

### 30 分ごとのタスク選択

「今から何をやる？」の画面でタスクを 1 つ選んで始めると、30 分後にまたこの画面が出ます。

| 操作                     | 内容                                                                            |
| ------------------------ | ------------------------------------------------------------------------------- |
| 入力欄に入力して Enter   | タスクを追加する                                                                |
| Enter / ダブルクリック   | 選んだタスクを 30 分はじめる（入力欄が空のときの Enter は「前回の続き」を開始） |
| Esc / ウィンドウを閉じる | 5 分後にもう一度表示する（スヌーズ）                                            |
| Backspace                | 選んだタスクを完了にする                                                        |
| ドラッグ                 | 並べ替える。ほかの分類の見出しの下に落とすと、分類も変わる                      |

タスクは、NOW（今すぐ）、ROUTINE（定期）、SOONER（近いうち）、ANYTIME（いつでも）、SOMEDAY（いつか）、BREAK（休憩）の 6 つの分類に分けて表示されます。

### 次の予定と作業ストップ

その日はじめてタスクを始めるときに、**次の予定の時刻**（席を立つ時刻）と、**何分前に作業を止めるか**（5〜30 分、初期値 15 分）を入れます。

- 時刻は `2330`、`930`、`9` のように数字だけでも入力できます。過ぎた時刻は翌日として扱います。
- 作業ストップの **5 分前** に警告が出ます。続きのメモを残しておけます。
- 作業ストップの時刻になると「次の予定の時間です」の画面になり、閉じられません。今日の作業時間とタスク別の時間が表示されます。「アプリを終了」で終わります。
- また使うときは、アプリを起動し直して、次の予定を入れ直します。
- 「今日」は朝 4:00 で区切ります。

### 作業中

画面の右端に、残り時間のリングが出ます（残り 5 分で橙色）。
マウスを乗せると、タスク名と「完了して次を選ぶ」ボタンが出ます。早く終わったときに使います。

### タスク管理

トレイメニューの「タスク管理」で開きます。タスク名・分類・メモの編集、検索、完了・未完了に戻す、削除ができます。

### トレイメニュー

| 項目                       | 内容                                                                                                 |
| -------------------------- | ---------------------------------------------------------------------------------------------------- |
| タスクを選ぶ               | タスク選択の画面を開く                                                                               |
| タスク管理                 | タスク管理の画面を開く                                                                               |
| 言語 / Language            | 日本語・English・OS の設定に従う から選ぶ（再起動で反映）                                            |
| Google でログインして同期… | この PC だけで使っているときだけ。Google でログインして、クラウドで同期を始める                      |
| 暗号化…                    | ログインしているときだけ。パスフレーズの変更、回復キーの再発行                                       |
| 再起動                     | アプリを起動し直す                                                                                   |
| ログアウト                 | ログインしているときだけ。この PC に保存されたデータと暗号を解く鍵も消える（クラウドのデータは残る） |
| 終了                       | アプリを終了する                                                                                     |

画面の左上（タスク管理は右上）の点で、データの状態がわかります。表示は「同期済み」「送信待ち」「オフライン」のどれかで、この PC だけで使っているときは「この PC のみ」です。

## 保存先を変える

**この PC だけ → クラウド**：トレイメニューの「Google でログインして同期…」を押して、ログインと暗号化の設定をします。
クラウドにまだタスクがなければ、この PC のタスクと作業の記録をクラウドにコピーするか聞かれます。コピーすると、この PC の `store.json` は `store.json.migrated` に名前が変わります。

**クラウド → この PC だけ**：トレイメニューの「ログアウト」のあと、「この PC だけで使う」を選びます。
この PC だけのデータは空の状態から始まります（クラウドのデータはコピーされません）。

## データの保存場所

この PC だけで使っているとき、データはすべて次のファイルにあります。バックアップしたいときは、アプリを終了してからこのファイルをコピーします。

| OS      | 場所                            |
| ------- | ------------------------------- |
| Windows | `%APPDATA%\shiodoki\store.json` |
| Ubuntu  | `~/.config/shiodoki/store.json` |

このファイルは暗号化していません。PC をほかの人と共有している場合は注意してください。

## 更新

- Windows：起動したときに新しいバージョンがあれば、お知らせが出ます。「更新する」を押すと、バックグラウンドでダウンロードします。終わると「今すぐ再起動」か「終了するときに更新」を選べます。「変更点を見る」で、ブラウザに変更点のページを開きます。
- Ubuntu：お知らせは出ません。[GitHub の Releases](https://github.com/kazi983/shiodoki/releases) から新しい `.deb` をダウンロードして、インストールと同じコマンドで入れます。

タスク、作業の記録、ログイン状態は引き継がれます。

## アンインストール

- Windows：「設定」→「アプリ」→「インストールされているアプリ」→ Shiodoki →「アンインストール」。
  - 設定とデータが `%APPDATA%\shiodoki` に残ります。不要なら削除してください。
- Ubuntu：`sudo apt remove shiodoki`。`~/.config/shiodoki` が残ります。

**この PC だけで使っていた場合、このフォルダを消すとタスクと作業の記録がすべて消えます**。
ログインして使っていた場合は、クラウドのデータは残ります。消したいときは [データとプライバシー](privacy.md) を見てください。

## 困ったとき

| 症状                                     | 対処                                                                                                                                                                      |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 「Windows によって PC が保護されました」 | 「詳細情報」→「実行」を押す                                                                                                                                               |
| ログインで「アクセスをブロック」         | 使っている Gmail アドレスを管理者に伝えて、登録してもらう                                                                                                                 |
| パスフレーズを忘れた                     | 回復キーで解除し、トレイメニューの「暗号化…」で新しいパスフレーズを決める                                                                                                 |
| パスフレーズと回復キーの両方をなくした   | ログインしたままの PC があれば、その PC の「暗号化…」で回復キーを再発行できる。なければクラウドのデータは読めないので、管理者に連絡してデータを消してから最初からやり直す |
| トレイのアイコンが見つからない           | Windows はタスクバー右下の「^」の中。Ubuntu は上の GNOME 拡張機能を入れる                                                                                                 |
| 「Shiodoki はすでに起動しています」      | 「前面に表示」で、起動中の画面を表示する                                                                                                                                  |
| 作業ストップのあとも作業したい           | アプリを終了して起動し直し、次の予定を入れ直す                                                                                                                            |
| そのほかの不具合                         | 管理者に連絡するか、[GitHub の Issues](https://github.com/kazi983/shiodoki/issues) に書く                                                                                 |
