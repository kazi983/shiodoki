# 用語集（日本語 ⇔ English）

- ステータス: 確定（2026-10-09 レビュー済み）
- 対象: デスクトップ・Android の両アプリの表示文言
- 目的: 英訳の表記ゆれを防ぐ。両アプリで同じ概念に同じ英語を使う

この表は「訳語の基準」であり、全文言の英訳ではない。全文言は実装時に辞書ファイル（デスクトップ: `desktop/src/shared/i18n/en.ts`、Android: `values/strings.xml`）に書き、PR でレビューする。

訳語を追加・変更するときは、この表を先に更新してから辞書ファイルを変える。

## 1. 英語の書き方の基本ルール（style guide）

| #   | ルール                                                                           | 例                                                                                                       |
| --- | -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| S-1 | ボタン・見出し・メニューは **sentence case**（最初の単語だけ大文字）             | `Add task`（`Add Task` にしない）                                                                        |
| S-2 | ボタンは動詞で始める                                                             | `Save changes`、`Mark as done`                                                                           |
| S-3 | 確認ダイアログは質問文にし、タスク名は curly quotes で囲む（日本語の「」に相当） | `Delete “Write report”?`                                                                                 |
| S-4 | 時間の単位は短縮形。数字と単位の間に半角スペース                                 | `30 min`、`5 sec`。累計時間だけは `h` / `m` を数字に続け、ゼロ埋めしない: `2h 5m`（日本語版も同じ。Q-1） |
| S-5 | 時刻は 24 時間表記 `HH:mm` のまま（日本語版と同じ）                              | `18:30`                                                                                                  |
| S-6 | 日付は英語版を `Oct 9` 形式にする（Q-3）。日本語版は `10-09` のまま              | `Oct 9`                                                                                                  |
| S-7 | 文体はくだけすぎない平易な口調。`please` は付けない                              | `Enter a task name`（`Please enter…` にしない）                                                          |
| S-8 | 複数形を正しく出す（`1 session` / `3 sessions`）                                 |                                                                                                          |
| S-9 | 言語選択の項目名は、その言語自身の表記（autonym）にする                          | `日本語` / `English`（`Japanese` にしない）                                                              |

### 作業ストップと離席時刻（訂正）

当初「デスクトップの UI は離席時刻を『作業終了』と呼んでいて用語がずれている」と書き、日本語を「離席」に揃えると決めたが、これは読み違いだった。

- 離席時刻（`leaveAt`）: 「次の予定」欄に入れる時刻。例 23:30
- 作業終了と書いていた時刻（`stopAt`）: 離席時刻から「何分前に止めるか」を引いた時刻。例 23:15。5 分前の警告とブロックはこの時刻が基準

「離席」に揃えると、23:30 と入力したのに「23:15 に離席」と表示されてしまう。そこで `stopAt` に **作業ストップ / Wrap up** という名前を付けた（§6）。

### Q-4 の補足: 英語のままにする文（開発者向け）の分け方（決定）

今はすべて日本語なので、「英語のまま」は「辞書に入れず、英語の文に書き換える（日本語の画面でも英語で出る）」という意味になる。次の分け方にする。

| 分類         | 文言（現在）                                                                      | 扱い                                                     |
| ------------ | --------------------------------------------------------------------------------- | -------------------------------------------------------- |
| 開発者向け   | `oauth-client.json` がない（desktop/README.md を見て置く）                        | 英語のみ                                                 |
| 開発者向け   | `client_id / client_secret がありません`                                          | 英語のみ                                                 |
| 開発者向け   | データ処理が停止した / 開始されていない / タイムアウトした                        | 英語のみ                                                 |
| 開発者向け   | データファイルを読み込めませんでした                                              | 英語のみ                                                 |

## 7. 「今から何をやる？」の英訳候補

アプリの看板になる問いかけで、デスクトップのタスク選択画面と Android のフォーカス画面の両方に出る。

| 候補                        | ニュアンス                                                                                               |
| --------------------------- | -------------------------------------------------------------------------------------------------------- |
| What will you work on now?  | 直訳に近く、意味がいちばん明確。「これからの 30 分」を `will` で表せる。やや長い                         |
| What are you working on?    | チャットの状況確認のような自然な口語。ただ現在進行形なので「今やっていること」を聞いているようにも読める |
| What's your focus now?      | 短い。Android の「Focus screen」と言葉がつながる。少し意識高めの響き                                     |
| What do you want to do now? | 「やる？」のくだけた感じにいちばん近い。作業以外も含む広い問いに聞こえる                                 |
| What's next?                | いちばん短い。ただし「次の予定（Next plan）」と紛らわしい                                                |
| Pick your next task         | 質問ではなく指示。他の見出し（`Pick one task for the next 30 min`）と重なる                              |

**決定: `What's your focus now?`**。短く、Android の「Focus screen」と言葉がつながる。
